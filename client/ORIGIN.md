# Source provenance

This client is adapted from the user-supplied `mc-main` directory.
Its original README is retained as README.md. The supplied archive did not
identify a repository URL or provide a project-wide LICENSE file.
The original authorship is not claimed by C-mine.

Existing license notices in stb_image and SimplexNoise are preserved.
The supplied textures are retained as provided; their provenance has not been
verified and they are not described as official Minecraft assets.

Local changes add CMake builds, serialized chunk updates, safe mesh replacement,
bounded loading, surface spawning, and safer initialization.
